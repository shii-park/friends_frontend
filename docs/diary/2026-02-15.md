- API連携の基盤となるサービス層を導入 (`src/services/api.ts`)
  - バックエンドとの通信を想定した非同期インターフェース (`apiService`) を作成
  - 通信遅延（`sleep`）を模倣し、ローディング演出のテストを可能に
- `useUser` hook を非同期処理に対応するようリファクタリング
  - `isLoading` 状態を追加し、通信中のUI制御を可能に

- 各画面を非同期API対応にアップデート

  - ガチャ画面 (`Gacha.tsx`)：抽選処理の非同期化と連打防止
  - ストレージ画面 (`Storage.tsx`)：強化処理の非同期化とローディング演出
- ビルドチェックと不具合修正
  - `useUser.tsx`, `Title.tsx` におけるコードの重複定義を修正
  - TypeScript の厳密な型チェック（未使用変数、型のみのインポート）への対応
  - `npm run build` による正常動作の確認
- ホーム画面のレイアウト刷新
  - ストレージとガチャを横長（Landscape）の形状に変更し、左側に縦並びで配置
  - バトルを正方形（Square）の形状に変更し、右側に大きく配置
  - 各カードのホバー演出（拡大・回転）を維持しつつ、新しい形状に合わせて調整
  - 未使用になったコード（`menuItems`）を整理
- ストレージの強化モーダルのUI刷新
  - モーダル内のレイアウト崩れを修正し、ブランドカラー（黒・ライム）に統一
  - モーダル外側の背景（オーバーレイ）の透明度をさらに上げ、背後のストレージ画面がより鮮明に透けて見えるように調整
  - ステータスの上昇変化を矢印アイコンを用いて分かりやすく可視化
  - 強化実行中のローディング表示（`isLoading`）をボタンに適用
