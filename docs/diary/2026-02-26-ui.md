# 2026-02-26 の変更内容 (UI改善・機能追加)

- ストレージ画面の「カード強化モーダル」を改善
  - 強化後のステータス予測値を具体的に表示する機能を追加
  - ドキュメントの計算式 `初期値 + (最大値 - 初期値) / 9 * 現在のレベル` を実装
  - 消費コインの表示にカンマ区切り（toLocaleString）を適用
- バトル画面の演出を大幅に強化（安定版）
  - ダメージ数値を大きくし、色分け（自分：赤、相手：黄）と浮き上がるアニメーションを適用
  - カード被弾時にブルブル震えるシェイク演出を `taking-damage` クラスにより実装
  - 攻撃側が前に出るアニメーションのロジック（`attacking` クラス）を修正
  - 決着時に「VICTORY!」または「LOSE...」をリッチなスタイルで表示
- バトル画面におけるカードステータス表示機能の実装
  - キャラクター（HP, ATK, TECH）および装備（HP+, ATK+, TECH+）をラベル付きで表示
