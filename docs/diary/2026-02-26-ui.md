# 2026-02-26 の変更内容 (UI改善・レイアウト調整)

- キャラクター/装備選択画面（BattlePrepare）のプレビューエリアを大幅に改善
  - 「YOU」と「ENEMY」を左右に配置し、中央に「VS」を配置する対戦形式のレイアウトに変更
  - 「ENEMY」側を少し上に、「YOU」側を少し下にずらすオフセット配置を適用し、ダイナミックなVS演出を表現
  - プレビュー内でのカード表示を「mini」サイズに戻し、左右配置でもバランス良く収まるように調整
  - バトルフローに合わせたページ遷移アニメーション（App.tsx）の改善（戻る時は左スライド）
  - カードリストにおいて「mini」表示を廃止し、通常サイズのカードを表示（ホバー不要でステータス確認可能に）
- バトル結果画面（BattleResult）のレイアウトを改善
  - 画面いっぱいに広がっていた表示を `max-width: 500px` に制限し、情報を中央に集約
- ストレージ画面の「カード強化モーダル」を改善
  - 強化後のステータス予測値を具体的に表示する機能を追加
- バトル画面の演出を大幅に強化（安定版）
  - ダメージ数値を大きくし、色分けと浮き上がるアニメーションを適用
  - カード被弾時にブルブル震えるシェイク演出を実装
  - 決着時に「VICTORY!」または「LOSE...」をリッチなスタイルで表示
