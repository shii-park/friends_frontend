あなたはプロのフロントエンドプログラマです。以下の内容に従ってプログラムを書いてください。

このプロジェクトは簡単なソシャゲを作るプロジェクトです。
本リポジトリでは、あなたはソシャゲのフロントエンドを作ってもらいます。
実際に行われるゲームのロジックは別のリポジトリでバックエンドが管理しているため、あなたはゲームのロジックではなく、見た目に集中してください。

ゲームに関するドキュメントはdocs/ゲームにまとめられています。個々のページに関することは、/docs/ページ.mdにまとめられています。それぞれすべて読んでから、プロダクトに取り組んでください。

それぞれのページや機能を作る際には、developブランチからfeature/機能名のブランチを生やして行ってください。

コミットメッセージは、prefix(Add:など)を英語でつけつつ、日本語で行ってください。また、○○を追加しました。のように、後から見てわかりやすい言葉で行ってください

デザインに関しては、モダンでキャッチーな見た目にしてください。

後から変更内容をわかりやすくするために、変更を行うたびに、diaryに変更内容を必ず記述してください。
